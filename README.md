# VEIL — Campo minado

Campo minado preciso, com tabuleiro diário, modo personalizado e estatísticas locais.

Feito com Grok.

## Jogar

- **Fácil** 9×9 · 10 minas
- **Médio** 16×16 · 40 minas
- **Expert** 30×16 · 99 minas
- **Diário** um tabuleiro por dia
- **Personalizado** tamanho e minas à sua escolha

Toque para revelar. Segure — ou clique com o direito — para marcar bandeira. O primeiro toque nunca cai em mina. Em um número, toque de novo para abrir os vizinhos (acorde).

Partida em andamento fica salva neste aparelho.

## Rodar local

```bash
npm install
npm run dev
```

Requer Node 22.
